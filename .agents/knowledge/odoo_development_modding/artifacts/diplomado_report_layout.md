# Diplomado report layout notes

Date: 2026-06-15

Module: `addons-extra/extrairg/irg_generacion_diplomados`

## Context

The diplomado PDF is generated by the QWeb template `reports/diplomado_templates.xml` using `web.html_container`, `web.basic_layout`, a custom landscape A4 paperformat, and static image assets under `static/src/img/`.

## Findings

- The wizard and registry keep `diplomado_name` as entered or copied from `op.course.name`; uppercase rendering was caused by CSS in the report template, not by Python logic.
- For QWeb PDF reports, avoid putting the full-page background image behind the page with a negative `z-index`. In wkhtmltopdf this can interact badly with page wrappers and apparent page scaling.
- When report content can grow, do not position independent headings and lists with unrelated absolute `top` values. Use one absolute content region and normal document flow inside it.

## Applied pattern

- Keep the A4 landscape container at `297mm x 210mm`.
- Reset margins/padding for `html`, `body`, `.article`, and `.page`.
- Place the background image at page size with `z-index: 0` and content above it with positive `z-index`.
- Keep long diploma names in a fixed centered title block with controlled width and `line-height`.
- Render reverse-page module sections inside a single `.back-content` container so presencial and online sections cannot overlap.
