# Módulos: addons-co

Carpeta con módulos de **localización colombiana** para ISEP/IRG en mercado Colombia. Incluye facturación electrónica colombiana (Jorels), nómina colombiana y herramientas auxiliares.

| l10n_co_hr_payroll | Nómina colombiana | Instalable |
| l10n_co_hr_payroll_inherited | Herencia de nómina colombiana | Instalable |
