# Módulos: pos

Carpeta con módulos OCA del repositorio `pos` para Odoo 16. Amplía el Punto de Venta (TPV) de Odoo con funcionalidades adicionales de descuentos, clientes, informes, pagos y gestión de pedidos.

Todos son módulos de terceros (OCA) y no deben modificarse directamente.

---
