# Módulos: account_financial_tools

Carpeta con módulos OCA (Odoo Community Association) del repositorio `account-financial-tools` para Odoo 16. Estos módulos amplían la funcionalidad contable de Odoo con herramientas adicionales de gestión financiera.

Todos los módulos son de terceros (OCA) y no deben modificarse directamente.

Estos módulos son independientes y pueden instalarse según necesidad. Consultar la documentación OCA oficial para requisitos específicos de cada uno.
