# Módulos: addons-mx

Carpeta con módulos de **localización mexicana** para ISEP/IRG en mercado México. Incluye nómina CFDI, sincronización SAT e integraciones fiscales del mercado mexicano.

---

## Índice de módulos

| Módulo | Descripción | Estado |
|--------|-------------|--------|
| l10n_mx_sat_sync_isep | Sincronización SAT (versión ISEP) | Instalable |
| l10n_mx_sat_sync_itadmin_ee | Sincronización SAT (ITAdmin Enterprise) | Instalable |
| nomina_cfdi_bancos | Nómina CFDI — Bancos | Instalable |
| nomina_cfdi_ee | Nómina CFDI Enterprise | Instalable |
| nomina_cfdi_extras_ee | Extras de nómina CFDI Enterprise | Instalable |
| nomina_cfdi_extras_ee_fix | Fix de extras de nómina CFDI | Instalable |
| nomina_cfdi_sua | Nómina CFDI SUA | Instalable |
| subscription_invoice_ee | Facturas de suscripción Enterprise (MX) | Instalable |
| uisep_xml_sat | XML SAT para UISEP | Instalable |
| duplicate_intercompany | Duplicar operaciones entre compañías | Instalable |
