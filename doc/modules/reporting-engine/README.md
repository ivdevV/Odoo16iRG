# Módulos: reporting-engine

Carpeta con los módulos OCA del repositorio `reporting-engine` para Odoo 16. Proporciona motores de informes adicionales y herramientas de análisis, incluyendo soporte para XLSX, py3o, QR, SQL, y mejoras al motor de informes QWeb estándar de Odoo.

Todos son módulos de terceros (OCA) y no deben modificarse directamente.

---

## Índice de módulos

### Informes XLSX

| Módulo | Descripción |
|--------|-------------|
| report_xlsx | Motor de informes en formato Excel (XLSX) |
| report_xlsx_helper | Helpers para informes XLSX |

### Informes py3o

| Módulo | Descripción |
|--------|-------------|
| report_py3o | Motor de informes py3o (LibreOffice) |
| report_py3o_fusion_server | Servidor de fusión py3o |

### Mejoras a informes QWeb

| Módulo | Descripción |
