# Módulos: vztech

Carpeta con módulos desarrollados por **DFVZ TECH** para el proyecto IRG/ISEP. Contiene extensiones del CRM y del pedido de venta, especialmente la base de integración bancaria SEPA necesaria para el sistema de cobros domiciliados.

---

## Índice de módulos

| Módulo | Descripción | Modelos afectados | Estado |
|--------|-------------|-------------------|--------|
| [irg_crm_extended](./irg_crm_extended.md) | Extensión del CRM con vistas y accesos | `crm.lead` | Instalable |
| [irg_sale_order_extended](./irg_sale_order_extended.md) | Pedido de venta con integración SEPA/banca | `sale.order` | Instalable |
