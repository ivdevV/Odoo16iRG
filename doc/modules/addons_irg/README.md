# Módulos: addons_irg

Carpeta con módulos adicionales específicos de IRG que no encajan en la categoría `extrairg`.

---

## Índice de módulos

| Módulo | Descripción | Estado |
|--------|-------------|--------|
| ised/ | Módulo ISED (estructura pendiente de validar) | Sin `__manifest__.py` detectado — no es módulo Odoo |

> **Nota:** El subdirectorio `ised/` no contiene `__manifest__.py` y por tanto no es un módulo Odoo instalable directamente. Puede contener scripts auxiliares o datos de migración.
