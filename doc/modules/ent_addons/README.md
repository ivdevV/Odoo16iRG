# Módulos: ent_addons

Carpeta con los **módulos Enterprise de Odoo 16**. Contiene la distribución completa de módulos propietarios de Odoo S.A. que amplían la funcionalidad de Odoo Community con características avanzadas de contabilidad, RRHH, ventas, fabricación, firma electrónica, social media, BI y localización para múltiples países.

> **Nota:** Estos módulos son propiedad de Odoo S.A. y están sujetos a la licencia Odoo Enterprise. No deben modificarse directamente. Todas las personalizaciones deben hacerse mediante módulos con `_inherit`.

---
