# Módulos: edi-framework

Carpeta con los módulos OCA del repositorio `edi` para Odoo 16. Proporciona el framework base de EDI (Electronic Data Interchange) de OCA para integración con sistemas externos mediante intercambio de documentos electrónicos.

Todos son módulos de terceros (OCA) y no deben modificarse directamente.

---
