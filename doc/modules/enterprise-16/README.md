# Módulos: enterprise-16

Carpeta con los módulos **OpenEduCat Enterprise** para Odoo 16. Extiende las funcionalidades de OpenEduCat Community con módulos avanzados de gestión educativa, eLearning, analítica y experiencia de usuario.

Estos módulos son de OpenEduCat (licencia comercial) y no deben modificarse directamente.
