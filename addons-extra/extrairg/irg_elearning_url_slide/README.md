# IRG eLearning URL Slide

Anade un tipo de contenido `URL` a eLearning (`website_slides`) para crear slides normales que enlacen a clases o recursos externos.

## Uso

1. Crear o editar un contenido dentro de un curso eLearning.
2. Seleccionar `URL` en `Tipo de contenido`.
3. Completar el campo `URL` con una direccion `http://` o `https://`.
4. Opcionalmente cambiar `Texto del boton`.

El alumno vera el contenido como un slide normal con un boton de acceso. El enlace se abre en la misma ventana.
