Installation

  • Download ODOO Moodle Connector module and place into addons directory
  • Restart Odoo server / service
  • Open setting, activate Developer Mode
  • Go to Apps
  • Update Apps List from top menu
  • Search the ODOO Moodle Connector and install it
  • Happy to use Moodle Cloud.


How Its Work


  • Login to Moodle Cloud Account
  • Click to Site Administration
  • Click to Plugins in Tab menu

  • Go to Web Services
  • Click to External Services

  • Click to Add button

  • Fill Service name field
  • Click Add Services button
  • Add Required service functions

  • Go back to Web Service
  • Click to Manage Tokens

  • Click on Add button

  • Select user from selection menu
  • Select a newly external service
  • Optional token lifetime

  • Install Odoo Moodle Connector
  • Go to eLearning
  • Click to Moodle Sync menu
  • Put credentials in fields
  • Click Import or Export button to store credentials

  • Click to Course Category
  • Add new categories

  • Click to Courses
  • Add new courses
  • Select course category

  • Go to Calendar
  • Click to view list button

  • Add new events
  • Select course
