# 16.0.1.1.0 — 2026-09-17

El informe de actividad se genera desde el Excel de listado (correo, curso con código entre paréntesis, nombre, país, modalidad), no desde un lote. El cruce es por correo y código de curso; las filas sin matrícula van a «No encontrados». El punto de entrada es OpenEduCat → Reporting → Informe de actividad.
